1. The difference between Git and GitHub is that Git is a system used to track changes locally, while GitHub is a platform for hosting and sharing reps.
2. The difference is that 'git add <file>' adds one specific file, 'git add .' adds all files in the current folder, and 'git add -A' adds all changes including deleted files.
3. The difference is that 'git push' uploads your commits to the remote rep, while 'git pull' downloads and merges changes from the remote rep to your local branch.
4. The difference is that 'git fetch' downloads changes from the remote repository without merging, while 'git pull' downloads and merges those changes.
